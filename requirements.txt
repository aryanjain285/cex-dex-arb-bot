# uvloop is a Linux/macOS-only C extension: its setup.py raises outright on
# Windows, which fails the whole `pip install -r requirements.txt` and takes
# every other dependency down with it. The marker keeps the documented install
# command working on the development platform while the deployment target
# (Linux) still gets the faster event loop. src/cli/main.py already treats the
# import as optional, and CI asserts the import succeeds on Linux so this
# marker cannot quietly disable it where it matters.
